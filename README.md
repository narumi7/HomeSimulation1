# HomeSimulation1 — おうち3Dシミュレーター

建物の **外観写真** と **間取り図** を読み込むと、家の外観から室内までを3Dで再現するWebアプリです。
ブラウザだけで動き、画像はサーバーに送信されません（すべて端末内で処理）。

## できること

- **間取り図の自動認識**：濃い線で描かれた壁を読み取り、壁の途切れを **窓**（外に面しているもの）や **ドア**（室内のもの）として判定
- **階ごとの読み込み**：1階・2階…と複数の間取り図を積み重ねて2階建て以上も表現
- **外観写真から色を取得**：写真から外壁と屋根の色を自動推定。写真をクリックして色を選び直したり、範囲をドラッグして外壁の模様として貼ったりもできる
- **屋根**：切妻・寄棟・片流れ・陸屋根から選択（勾配・軒の出・棟の向きも調整可）
- **3つの見方**
  - 外観：家の周りをぐるっと回して見る
  - 内観（上から）：屋根と上の階を外して、間取りを立体的に見下ろす
  - ウォークスルー：人の目線で室内を歩く（ドラッグで見回し、WASD・矢印キーで移動。スマホは画面のボタン）。階段を歩くと上の階・下の階へ移動できる
- **階段**：エディタで下の階に「階段」を塗ると、上の階へ上れる階段ができる（上の階の床は吹き抜けになり、手すりが付く）
- **間取りの手直し**：自動認識がうまくいかない所は「間取りを調整」タブで壁・窓・ドア・玄関ドアを塗って修正
- **書き出し**：3Dモデル（.glb）と画像（.png）を保存

## 使い方

1. 「写真を選ぶ」で外観写真を読み込む（任意）
2. 「間取り図を追加」で間取り図を読み込む（階ごとに複数可）
3. 各階の **建物の横幅 (m)** を実際の寸法に合わせる（外壁の端から端まで）
4. 必要に応じて「間取りを調整」タブで壁や窓を修正する
5. 「外観」「内観」「ウォークスルー」で確認

まずは「サンプルで試す」ボタンで、2階建てのサンプルの家を見られます。

### うまく認識させるコツ

- 壁が黒や濃いグレーの太い線で描かれた間取り図が向いています
- 壁が拾えないときは「線の濃さ」を上げ、文字や家具まで壁になるときは下げてから「自動認識をやり直す」
- 壁の厚みの自動推定がずれるときは「壁の厚み」を手動で指定
- 玄関ドアと階段は自動では判別しないので、エディタの「玄関ドア」「階段」で塗ってください
- 階段は **下の階** の間取りに塗ります。上る向きは、上の階で床につながっている側が上端になるよう自動で決まります
- 2階が1階とずれるときは、階ごとの「左右にずらす／前後にずらす」で位置合わせ

## GitHub Pages で公開する

ビルド不要の静的サイトなので、そのまま GitHub Pages で公開できます。

1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を **Deploy from a branch** にする
3. Branch で `main`（フォルダは `/ (root)`）を選んで **Save**
4. 数分後に `https://<ユーザー名>.github.io/HomeSimulation1/` で見られるようになります

## ローカルで動かす

ES Modules を使っているため、ファイルを直接開くのではなく簡単なサーバー経由で開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## 構成

```
index.html            画面
css/style.css         見た目
js/main.js            画面の操作・全体の流れ
js/planAnalyzer.js    間取り図の解析（壁の抽出・窓/ドアの判定）
js/houseBuilder.js    解析結果から3Dの家（壁・床・天井・窓・屋根）を生成
js/viewer.js          3D表示（外観／内観／ウォークスルー）
js/photo.js           外観写真からの色・模様の取得
js/textures.js        外壁・屋根・床などのテクスチャ
js/sample.js          サンプルの間取り図と外観
vendor/three/         three.js (MIT License)
```

## 制限事項

- 屋根は最上階の外形を長方形とみなしてかけます（L字などの複雑な形は近似）
- 家具・設備は再現しません
- 階段はまっすぐな直階段として作ります（折り返し・回り階段は近似）
- 外観写真は色と模様の参考として使い、写真から形を復元するものではありません
